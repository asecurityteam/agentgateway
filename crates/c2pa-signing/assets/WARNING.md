# SECURITY WARNING

The credentials generated in this directory (`private.key` and `certificate.pem`) are **SOLELY FOR TESTING AND DEMONSTRATION PURPOSES**. Do not commit them.

For production use, you should:

1. Generate secure keys in a protected environment.
2. Obtain a certificate from a trusted C2PA-compliant Certificate Authority.
3. Use a secure Key Management System (KMS) or Hardware Security Module (HSM) to handle signing operations.

## Test Credentials

Run `make certs` to generate valid test credentials.
